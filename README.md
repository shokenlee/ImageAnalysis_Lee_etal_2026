# ImageAnalysis_Lee_etal_2026

ImageJ macro scripts for Lee et al. 2026 Nature Communications "Screening of amphipathic helices identifies features linked to inner nuclear membrane properties"

Tested with Fiji ImageJ version 2.14 on Mac OS 2023-2024.

## Scripts
- NE_enrich_score_sirDNA_trueNP.ijm: NE enrichment score analysis
- GUV_Enrichment_Score.ijm: GUV image analysis
